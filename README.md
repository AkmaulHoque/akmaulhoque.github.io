# Akmaul Hoque — GIS & Remote Sensing Portfolio

Interactive single-page portfolio for **Akmaul Hoque**, GIS Developer and Remote Sensing & Geospatial Professional.

## Features
- Responsive single-page portfolio
- Interactive skill filtering
- Scroll-reveal animations
- Mobile navigation
- GIS-inspired hero visualization
- Resume download
- GitHub, LinkedIn, email and phone links
- No framework or build step required

## Local preview
Open `index.html` in a browser, or serve the folder with any static server.

## GitHub Pages deployment
For a personal GitHub Pages site, create a public repository named:

`AkmaulHoque.github.io`

Upload all files from this folder to the repository root. GitHub Pages will then publish the site at:

`https://akmaulhoque.github.io/`

If Pages does not activate automatically, use **Repository Settings → Pages → Deploy from a branch → main / root**.
